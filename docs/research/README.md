# Desktop evolution research

Planning date: **2026-10-22**. Research uses public first-party documentation and a source audit of the existing repository. It is not a hands-on competitor benchmark, a new live-provider qualification, a security audit or an installer test.

- [Competitive analysis](competitive-analysis.md): Simplify, Teal, LoopCV, Jobright, Huntr, Rezi, LazyApply and Sonara. Vendor claims are labeled; unverified capability means unknown, not absent.
- [OpenCode runtime and models](opencode-runtime-and-models.md): runtime vs hosted provider, v2 client/SDK, actual adapter gaps, local/hosted model paths and qualification work.
- [Desktop, Core and Connect](desktop-core-connect.md): Tauri/Electron tradeoffs, SQLite migration, secrets, browser packaging, native Gmail OAuth, optional Composio, encrypted accountless relay and mobile distribution.
