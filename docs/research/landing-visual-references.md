# Landing visual reference study — 2026-10-22

The user asked for a replacement of the lavender page, with a pure-black foundation and three or four colors. Public pages were inspected through rendered browser captures at 1440 × 1000, including hero, post-hero section and footer. Captures remain local review evidence.

- [T3 Code](https://t3.codes/): large readable promise, restrained navigation, provider recognition, clear download action and substantial product evidence. Pursuit keeps the clarity and scale; it does not reuse floating icon artwork, customer claims or source code.
- [Diffusion Studio](https://diffusion.studio/): cinematic motion, a black canvas and a clear transition from atmosphere to actual product. Pursuit uses an original local WebGL trajectory field; no planet or dock assets are copied.
- [Neatlogs](https://neatlogs.com/): sequential visual explanation after the hero, persistent work context, and a broad resource directory in the footer. Pursuit adapts the narrative structure to a career brief and uses its own interface, source text and mark.

Implemented palette: black `#000000`, ivory `#f5f5ef`, acid yellow `#d5f578`, ice blue `#7bc8f6`, with neutral ramps and quiet state tints. Each signal has a role rather than tinting every heading or entire card.

The hero's animation is decorative. Workflow examples are illustrative, not live application proof. The actual harness screenshot is an unmocked browser renderer capture with disconnected native storage visibly disclosed. No unavailable submission executor or public installer is presented as working.
